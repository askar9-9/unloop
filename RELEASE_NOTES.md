# Unloop 0.1.1

- Проект и название приложения переименованы из Still в Unloop.
- Текущий интерфейс и функции сохранены; концепт нового дизайна в этот релиз не входит.
- Instagram Reels и YouTube Shorts: маскировка распознанных кнопок и выход при перелистывании.
- Экранное время, недельная статистика и помощь с системным чёрно-белым режимом.
- Локальное хранение настроек и истории прерываний.

APK предназначен для личного тестирования и подписан отладочным ключом. Для обновления установленного APK нужна та же подпись. Сборка GitHub Actions использует собственный отладочный ключ и может потребовать переустановки локальной версии.

Android 10+. Защита Instagram/YouTube экспериментальная и зависит от версии интерфейса приложений. Список сценариев проверки — в TESTING.md.

Android applicationId сохранён как `app.still`, чтобы переименование само по себе не меняло установленное приложение и его данные.
