# Unloop 0.4.1

- Нижняя панель на всю ширину экрана, как в Instagram: только иконки, выбранная — жирнее. Новые иконки: пульс («Сегодня»), знак Unloop («Защита»), глаз («Экран»).

- Исправлено: в истории по дням иконки приложений не совпадали с названиями.

# Unloop 0.4.0

- Шортсы в YouTube: свайп к следующему ролику снова выводит из ленты. YouTube 21.x перестал сообщать о прокрутке, поэтому Unloop теперь замечает смену самого ролика.
- Обновления: Unloop раз в день проверяет новый релиз на GitHub и присылает уведомление; в «Настройках» есть кнопка «Проверить обновления». «Обновить» скачивает APK, сверяет контрольную сумму и открывает системную установку.
- История по дням: нажмите на столбик недели, чтобы увидеть приложения за этот день; стрелками можно листать прошлые недели. Завершённые дни сохраняются на телефоне (до 90 дней), потому что Android хранит события только около недели.
- Настоящие иконки Instagram, YouTube и приложений в статистике.

Новые разрешения: интернет (только GitHub для обновлений), установка приложений (только обновления Unloop), уведомления.

# Unloop 0.3.0

- Пошаговое подключение защиты. Кнопка открывает спецвозможности. Если Android запретил доступ (APK установлен не из Play), следующая кнопка ведёт прямо в «Сведения о приложении» с подсказкой: ⋮ → «Разрешить ограниченные настройки».
- Новый значок: петля с разрывом и точка, выходящая наружу. Адаптивная иконка с поддержкой тематических значков Android 13+.
- Меньше текста: короткие заголовки, без пояснительных абзацев. «Отозвать согласие» перенесено в «Настройки».

# Unloop 0.2.0

- Новый дизайн: монохромный интерфейс, тёмная и светлая темы по системной настройке телефона, шрифт Onest.
- Нижняя навигация заменена плавающим доком из трёх иконок без подписей: «Сегодня», «Защита», «Экран». Название раздела видно по долгому нажатию и в TalkBack.
- Состояние защиты видно с любого экрана: точка на кнопке «Защита» зелёная, когда защита работает, и жёлтая, когда нужна настройка.
- Экран «Сегодня»: баннер состояния защиты, крупная цифра экранного времени, недельный график, время по приложениям.
- Экран «Защита»: общий переключатель и строки Instagram и YouTube с перечнем того, что скрывается и что остаётся доступным.
- Экран «Экран»: превью «цвет / оттенки серого» и пошаговая инструкция для системного чёрно-белого режима.
- Проверка распознавания и удаление локальной истории перенесены в «Настройки» (шестерёнка вверху).
- Логика защиты, распознавания и хранения данных не менялась.

APK предназначен для личного тестирования и подписан тем же отладочным ключом, что и 0.1.1 (SHA-256 сертификата `6cc92a8d…967dc4`), поэтому устанавливается поверх без потери истории.

Android 10+. Защита Instagram/YouTube экспериментальная и зависит от версии интерфейса приложений. Список сценариев проверки — в TESTING.md.
