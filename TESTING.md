# Проверка Unloop 0.1.1

## Текущий статус

| Проверка | Результат |
| --- | --- |
| Компиляция Kotlin/Compose | Пройдена напрямую компилятором Kotlin 2.1.20 и Compose plugin 2.1.20 |
| Модульные тесты | 23/23 пройдены через JUnit 4.13.2 на JDK 17 |
| SDK / Java | Установлены Android SDK 35, Build Tools 35.0.0 и Temurin 17 |
| Стандартная сборка Gradle / lint | Заблокированы ограничением среды агента: `java.net.SocketException: Operation not permitted` |
| Debug APK | Собран локально, Unloop 0.1.1, versionCode 2, arm64-v8a |
| Подпись APK / zipalign | Проверены `apksigner verify` и `zipalign -c -P 16 4` |
| Ресурсы | Релинкованы AAPT2 с сохранением всех прежних resource IDs; новое название Unloop подтверждено `aapt dump badging` |
| Реальное устройство / эмулятор | Повторный запуск версии 0.1.1 агентом не проверен |
| Проверенные версии Instagram / YouTube | Нет |
| Примеры деревьев для unit-тестов | Синтетические, не подтверждают совместимость приложений |

Результаты статических проверок исходников описываются отдельно: они не заменяют компиляцию и проверку на телефоне.

Проверено локально: синтаксис shell-скриптов, разбор XML, соответствие компонентов манифеста исходникам, защита сервиса системным разрешением, отсутствие INTERNET и отключение резервного копирования. Все 23 модульных теста скомпилированы и исполнены; инструментальный тест Room не запускался.

Локальный APK получен прямой компиляцией Kotlin/Compose, включая ранее сгенерированные KSP-классы неизменённой схемы Room, линковкой ресурсов AAPT2 со стабильными ID и сборкой D8. Неизменённые зависимости и native-библиотеки использованы из предыдущей сборки этого проекта. Подписан существующим локальным debug-ключом. Это не результат запуска полного Gradle/lint-конвейера; такой запуск должен дополнительно пройти в CI. Артефакт не содержит `testOnly` и может устанавливаться обычным способом на arm64-устройство Android 10+.

## Матрица ручной приёмки

Перед проверкой записать модель телефона, Android, версии обоих приложений, язык и системную тему. Начать с обычных официальных приложений на одном полноэкранном окне. Повторить ключевые сценарии в светлой/тёмной теме и RU/EN.

| Сценарий | Ожидаемое поведение |
| --- | --- |
| Запуск без разрешений | Объяснение необходимых доступов; вместо статистики — приглашение разрешить доступ |
| Отмена согласия | Переход к системному включению сервиса не выполняется |
| Подключение только Accessibility | Защита может работать; статистика всё ещё запрашивает свой доступ |
| Нижняя навигация Instagram | Кнопка Reels закрыта, нажатие не открывает раздел; соседние кнопки работают |
| Нижняя навигация YouTube | Кнопка Shorts закрыта; соседние кнопки работают |
| Переписка / поиск / обычные видео | Маски и выход не мешают работе |
| Ссылка на ролик из переписки | Первый ролик доступен, автоматического выхода при открытии нет |
| Свайп к следующему ролику после 0,7 с | Выполняется возврат; если остался тот же плеер — переход «Домой» |
| Много событий одного свайпа | Одно прерывание, без серии возвратов |
| Прокрутка комментариев / ответов | Выход не выполняется |
| Возвращение в ленту после выхода | Начинается новая сессия с одним доступным роликом |
| Переход в другое приложение | Маски удалены, отложенный выход не отправляет другое приложение на главный экран |
| Неизвестная структура интерфейса | Нет произвольной маски; статус не утверждает, что защита подтверждена |
| Поворот / клавиатура / системное окно | Нет масок на чужих элементах; расположение пересчитывается |
| Блокировка телефона | Маски удалены; время заблокированного экрана не добавляется |
| Общий выключатель / переключатель приложения | Маски снимаются, выход отключается для соответствующего приложения |
| Отзыв согласия / системного доступа | Обработка интерфейса и маски прекращаются |
| Перезапуск приложения / телефона | Настройки сохранены; статус соответствует реальному доступу |
| Контролируемая сессия 2 минуты | Отчёт отражает время с учётом округления и задержки событий Android |
| Открытие отчёта после полуночи | Сегодня, график и счётчик относятся к новому дню |
| Удаление истории | После подтверждения счётчик обнулён; настройки и системная статистика сохранены |
| Чёрно-белый режим | Открываются настройки или общий fallback; инструкция не обещает автоматическое изменение цвета |

Если скрытие кнопки или отличие ролика от комментариев не подтверждается, записать конкретную комбинацию телефона/версии как неподдержанную и исправить сигнатуру до объявления совместимости. Не сохранять реальные переписки или полные деревья с личными данными в тестовые fixtures.
